# Тёмный рубеж

Браузерная tower defence в стиле тёмного фэнтези. React 19 + Vite 8 + TypeScript + Tailwind 4,
игровой движок свой (Canvas 2D, без игровых библиотек), звук синтезируется через Web Audio.
Фигуры башен, врагов и боссов — спрайты из `public/sprites/` (см. «Спрайты»); всё остальное
рисуется кодом. Проект начат в Google AI Studio, его остатки убраны.

Владелец — Артур, играет сам, на телефоне и компьютере (macOS). Общение — по-русски.

## Правила

- **Интерфейс игры только по-русски.** Все видимые игроку строки (названия, описания, подсказки,
  ошибки валидации) пишутся по-русски. Идентификаторы и комментарии в коде — как в окружающем коде.
- **Без внешних сервисов, ключей и входа.** Никаких API, серверов, аналитики, CDN, аккаунтов,
  `.env`-секретов. Игра целиком работает в браузере офлайн; прогресс хранится в `localStorage`.
- **Баланс и механику меняем только по замечаниям Артура.** Числа в `config.ts` и формулы в
  `rules.ts` без его просьбы не трогать (рефакторинг без изменения поведения — можно).
- **Одна правка — один коммит.** После каждой правки прогнать lint, тест и сборку (см. ниже).
- **В `main` не вливать без явного «да» Артура.** Работа идёт в отдельной ветке.
- Должно работать и на телефоне (касания, альбомная ориентация), и с клавиатуры на компьютере.
- При нескольких равноценных вариантах — спросить Артура (2–3 варианта, критерий, рекомендация);
  если оптимальный вариант очевиден — решать самому.

## Команды

```bash
npm install          # установка зависимостей
npm run dev          # дев-сервер на http://localhost:3000 (слушает 0.0.0.0 — можно открыть с телефона в той же сети)
npm run lint         # проверка типов: tsc --noEmit
npm test             # тест логики src/game/logic.test.ts (node:test через tsx)
npm run build        # сборка в dist/
npm run preview      # локальный просмотр сборки
```

Проверка после каждой правки: `npm run lint && npm test && npm run build`.

Выкладка: `.github/workflows/pages.yml` на каждом PR прогоняет lint, тест и сборку, а при вливании в
`main` выкладывает `dist/` на GitHub Pages (https://tzzoteozztot-ui.github.io/game/). Сборка с
`base: './'`, поэтому все пути в коде — относительные (`sprites/…`, а не `/sprites/…`).

## Архитектура

```
index.html               точка входа, lang="ru", мета для мобильных
src/main.tsx             монтирует <App/>
src/index.css            @import "tailwindcss", высота html/body/#root 100%, отступы под вырез экрана
src/fullscreen.ts        кнопка «Во весь экран» (Fullscreen API, клавиша F), признак запуска с экрана «Домой»
public/manifest.webmanifest, public/icons/  установка на экран «Домой» (значки — scripts/make_icons.py)
src/App.tsx              корневой компонент: экраны (menu → briefing → playing), магазин,
                         клавиатура, ввод с холста, сохранение прогресса, связь с движком
src/components/          UI-оверлеи поверх холста (чистый React + Tailwind)
  MainMenu.tsx           выбор уровня/сложности, звёзды, настройки звука
  LevelBriefing.tsx      описание фракции и босса перед уровнем
  TopBar.tsx             верх боковой колонки: золото, жизни, волна; скорость, звук, пауза
  ShopPanel.tsx          5 карточек башен, реролл, повышение тира
  TowerPanel.tsx         выбранная башня: приоритет цели, слияние, связка, продажа
  SpecModal.tsx          выбор специализации башни
  StatusModals.tsx       пауза, победа, поражение, «Как играть»
  OrientationWarning.tsx просьба повернуть телефон
  Icons.tsx              SVG-иконки
src/game/                логика и движок, без React
  config.ts              все константы и баланс: сетка 17×11, замок в центре, башни, враги, фракции, волны,
                         магазин, сложность, палитры уровней
  rules.ts               чистые формулы: стартовое золото, HP/число врагов, награды, продажа,
                         звёзды, расчёт урона, замедление
  towerStats.ts          параметры атаки башни по типу, уровню и списку специализаций (сила ×n)
  maps.ts                5 фиксированных карт (пути через makePath) и validateMap/validateAllMaps
  engine.ts              класс GameEngine: игровой цикл (requestAnimationFrame, шаг ≤ 0,05 с,
                         скорость ×0,5–×3 умножает игровое время, таймер волны — реальное), спавн, ИИ врагов и боссов, атаки
                         башен, снаряды, частицы, рендер на canvas
  audio.ts               процедурный звук (Web Audio), синглтон `sound`, настройки в localStorage
  sprites.ts             загрузка public/sprites/, подготовка вариантов (оттенок фракции, вспышка),
                         drawSprite с зеркалом по направлению и позой (подскок, наклон, сжатие)
  logic.test.ts          тесты карт и формул (node:test)
```

Поток данных: `App` создаёт один `GameEngine`, отдаёт ему canvas, вызывает публичные методы
(`startLevel`, `startNextWave`, `placeTower`, `mergeSelectedTower`, `sellTower`, `upgradeTier`…).
Движок сообщает о себе через колбэки `onStateChange(GameStateSnapshot)` и `onNeedSpecChoice(tower)`;
React хранит снимок в состоянии и рисует по нему оверлеи. Сам холст React не перерисовывает.
Для отладки движок доступен как `window.gameEngine`.

Магазин (генерация карточек, тройки) живёт в `App.tsx`, а не в движке.

Боковая колонка забирает всю ширину справа от поля (поле всегда во всю высоту, если хватает
ширины). Она — size-контейнер: размеры шрифтов и кнопок задаются переменными `SIDE_VARS` в
`App.tsx` (`--fs-*`, `--h-*`) через `cqh`/`cqw` с минимумами для телефона, а по высоте колонки
`@container` включает описания свойств и раскладку кнопок башни 2×2.

Ключи `localStorage`: `dark_frontier_unlocked`, `dark_frontier_stars`, `dark_frontier_sound`,
`dark_frontier_endless_best` (рекорд волны бесконечного режима по уровням).

## Спрайты

```
art/concepts/            исходные листы концептов 1536×1024 (towers, enemies, bosses,
                         enemies/factions — враги пяти фракций, enemies/ice-legion — ледяной легион)
scripts/slice_sprites.py нарезка листов: прозрачный фон без ореола, рамки и размеры фигур
public/sprites/          PNG (tower_*, enemy_*, enemy_<тип>_<уровень>, boss_1..5) и sprites.json
```

`sprites.json` для каждой фигуры хранит размер файла, `drawH` (высота на поле в px; файл втрое
крупнее), точку привязки по низу (`anchorX`, `anchorY`) и `facing` (куда смотрит на листе).
Перенарезка: `python3 scripts/slice_sprites.py` (нужны numpy и Pillow).
Лист-каталог всех персонажей с подписями — `docs/characters.png`; пересобрать: `npm run dev`, затем
`node scripts/character_sheet.mjs` (нужен Playwright, фигуры рисует сам движок). Враг рисуется спрайтом своей
фракции `enemy_<тип>_<уровень>` в его цветах, если такой есть; иначе общий `enemy_<тип>` получает оттенок
цвета фракции кодом. Анимация — только преобразования спрайта в `engine.ts`: шаг врага
(`GAIT`, от пройденного пути), парение летунов, дыхание и отдача башни после выстрела, падение
убитого врага (`corpses`, не больше 30), кольца уровня и значок специализации башни рисуются кодом. Если спрайт не
загрузился, движок рисует прежние геометрические фигуры.

## Игровые правила (кратко)

- 5 уровней, у каждого своя фракция с особенностью и боссом; 12 волн, в последней — босс.
- Бесконечный режим (выбор в меню, `engine.endless`, `CONFIG.endless`): 12 волн повторяются по кругу
  (`waveDefinition`), босс каждую 12-ю волну, HP растёт с номером волны без предела, каждый пройденный
  круг даёт +25 % врагов и +60 % HP босса, между волнами 45 с. Победы нет, хранится рекорд волны.
- 4 башни (Стрелок, Жрец, Маг, Баллиста), по 3 специализации. Три башни одного типа и уровня
  сливаются в башню следующего уровня (макс. 3). Ур.3 хранит специализации всех трёх башен Ур.2
  (`Tower.specs`), повтор одной специализации — её сила n: прибавка ×n, недостатки как при n = 1
  (формулы в `src/game/towerStats.ts`).
- «Связка» (`CONFIG.binder`, шансы `CONFIG.shop.binderChances`, с 3-го яруса лавки) ставится на поле
  отдельной фигурой (`engine.binders`). Выбранная башня + «Связать» + касание башни другого вида:
  вторая башня становится `Tower.second` (стреляет из той же клетки своими параметрами), связка
  тратится. Связанные башни не сливаются. Три связки сливаются в тройную (`Binder.triple`, выбор
  Артура): она поднимает любую башню или пару на уровень (каждую её часть ниже Ур.3,
  `upgradeWithBinder`); Ур.1 → Ур.2 просит свойство, Ур.2 → Ур.3 повторяет своё свойство трижды.
- Между волнами (идёт таймер, врагов нет — `engine.canMoveTowers()`) выбранную башню можно
  бесплатно переставить на свободную клетку: касанием клетки или перетаскиванием.
- Ограничения карт (константы в `maps.ts`, проверяются в `validateMap` и тесте): поле 17×11,
  замок — одна клетка в центре (8, 5), входы на краю поля, каждый путь кончается у замка;
  путь ≥ 26 клеток, дорога ≤ 90 клеток, свободных клеток ≥ 96, повороты только под 90°;
  участки дороги не соприкасаются сторонами, кроме мест, где путь переходит из клетки в клетку
  (слияния веток).
- Звёзды за уровень: ≥ 15 жизней — 3, ≥ 8 — 2, иначе 1.

При изменении формул в `rules.ts` или карт в `maps.ts` — обновлять `logic.test.ts`.
