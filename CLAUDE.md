# Тёмный рубеж

Браузерная tower defence в стиле тёмного фэнтези. React 19 + Vite 8 + TypeScript + Tailwind 4,
игровой движок свой (Canvas 2D, без игровых библиотек), звук синтезируется через Web Audio.
Фигуры башен, врагов и боссов — спрайты из `public/sprites/` (см. «Спрайты»); всё остальное
рисуется кодом. Проект начат в Google AI Studio, его остатки убраны.

Владелец — Артур, играет сам, на телефоне и компьютере (macOS). Общение — по-русски.

## Правила

- **Интерфейс игры только по-русски.** Все видимые игроку строки (названия, описания, подсказки,
  ошибки валидации) пишутся по-русски. Идентификаторы и комментарии в коде — как в окружающем коде.
- **Без внешних сервисов, кроме аккаунтов.** Никаких API, аналитики, CDN, `.env`-секретов. Игра
  целиком работает в браузере без входа; прогресс хранится в `localStorage`. Единственное исключение
  (выбор Артура, 2026-10-24) — необязательный аккаунт на Supabase (`src/cloud.ts`): вход через Google или по коду из
  письма, синхронизация прогресса между устройствами. В коде только публичный anon-ключ, доступ к
  строкам ограничен RLS; ключ service_role в репозиторий не класть.
- **Баланс и механику меняем только по замечаниям Артура.** Числа в `config.ts` и формулы в
  `rules.ts` без его просьбы не трогать (рефакторинг без изменения поведения — можно).
- **Одна правка — один коммит.** После каждой правки прогнать lint, тест и сборку (см. ниже).
- **В `main` не вливать без явного «да» Артура.** Работа идёт в отдельной ветке.
- Должно работать и на телефоне (касания, альбомная ориентация), и с клавиатуры на компьютере.
- При нескольких равноценных вариантах — спросить Артура (2–3 варианта, критерий, рекомендация);
  если оптимальный вариант очевиден — решать самому.

## Команды

```bash
npm install          # установка зависимостей
npm run dev          # дев-сервер на http://localhost:3000 (слушает 0.0.0.0 — можно открыть с телефона в той же сети)
npm run lint         # проверка типов: tsc --noEmit
npm test             # тест логики src/game/logic.test.ts (node:test через tsx)
npm run build        # сборка в dist/
npm run preview      # локальный просмотр сборки
```

Проверка после каждой правки: `npm run lint && npm test && npm run build`.

Тест баланса ботом: `npm run dev`, затем `node scripts/balance_sim.mjs out.json [--runs=N] [--only=endless|campaign|mono]`
(нужен Playwright; бот играет на настоящем движке с игровым временем, итог — JSON с уроном, золотом и прорывами).

Выкладка: `.github/workflows/pages.yml` на каждом PR прогоняет lint, тест и сборку, а при вливании в
`main` выкладывает `dist/` на GitHub Pages (https://tzzoteozztot-ui.github.io/game/). Сборка с
`base: './'`, поэтому все пути в коде — относительные (`sprites/…`, а не `/sprites/…`).

Поток данных: `App` создаёт один `GameEngine`, отдаёт ему canvas, вызывает публичные методы
(`startLevel`, `startNextWave`, `placeTower`, `mergeSelectedTower`, `sellTower`, `upgradeTier`…).
Движок сообщает о себе через колбэки `onStateChange(GameStateSnapshot)` и `onNeedSpecChoice(tower)`;
React хранит снимок в состоянии и рисует по нему оверлеи. Сам холст React не перерисовывает.
Для отладки движок доступен как `window.gameEngine`.

Магазин (генерация карточек, тройки) живёт в `App.tsx`, а не в движке.

Раскладка зависит от формы окна (`pickLayout` в `App.tsx`, ResizeObserver, выбор Артура 2026-10-31: «под любой экран как будто сделано под него»): на широких экранах — боковая колонка справа, на более квадратных (iPad, 4:3, 16:10) — полоса под полем (`BOTTOM_VARS`, высота от 150 px, в дуэли 176): лавка, рюкзак и кнопки в ряд, `--shop-cols`, `--ctl-cols`, `--ctl-w`, список скоростей открывается вверх (`dropUp`); выбирается та, где поле крупнее.

Боковая колонка — кнопки игры (`GameControls`: скорость, звук, весь экран, пауза — перенесены с поля 2026-10-31), лавка и рюкзак
(в дуэли ещё вкладки «Башни»/«Армия»). Поле занимает всю высоту, колонка — остаток ширины, не уже `max(132px, 12cqw)` и не шире
340 px (просьба Артура 2026-10-31: без полос вокруг поля); в узкой колонке подписи короче — «Лавка», «Ярус 1→2», в руке только
название, у «Обновить» и врагов армии только значок. В бою поле заходит под вырез камеры (`#root:has(.game-stage)` без боковых
отступов), колонка держит свой отступ справа. Золото, жизни, волна и карточка башни —
полупрозрачные оверлеи на поле; касания берут только их кнопки. Колонка — size-контейнер: размеры шрифтов и кнопок задаются
переменными `SIDE_VARS` в `App.tsx` (`--fs-*`, `--h-*`) через `cqh`/`cqw` с минимумами для телефона.

Ключи `localStorage`: `dark_frontier_unlocked`, `dark_frontier_stars`, `dark_frontier_sound`,
`dark_frontier_autostart`, `dark_frontier_endless_best` (рекорд волны бесконечного режима по уровням), `dark_frontier_auth`
(сессия Supabase). Звёзды и рекорд волны бесконечного режима хранятся отдельно по сложностям (`stars` и `endlessBest`: `easy|normal|hard`, уровень → число); старые общие значения при чтении переходят в «Обычную». Рекорд пишется с началом каждой волны, поэтому выход в меню посреди забега его не теряет. Прогресс привязан к владельцу (выбор Артура 2026-10-27): гостевой — в ключах выше, у каждого аккаунта своя копия на устройстве `dark_frontier_progress_<id>`; вход в другой аккаунт или выход подменяет прогресс, чужой не подмешивается. Гостевой переносится в аккаунт один раз, только если у аккаунта (устройство + облако) прогресса ещё нет, и после переноса гостевая копия обнуляется. В аккаунте прогресс лежит в таблице `progress` (`user_id`, `data` jsonb); при
входе копия аккаунта на устройстве и облачная сливаются по максимуму (`mergeProgress`). Таблица и правила RLS —
`supabase/progress.sql`; в шаблоне письма Magic Link стоит код `{{ .Token }}`, а не ссылка.

## Спрайты

```
art/concepts/            исходные листы концептов 1536×1024 (towers-tiers — башни по ярусам, PNG со своей прозрачностью, enemies, bosses,
                         enemies/factions — враги пяти фракций, enemies/ice-legion — ледяной легион;
                         props/ — связка, тройная связка и замок: снимки экрана на тёмном фоне-градиенте)
scripts/slice_sprites.py нарезка листов: прозрачный фон без ореола, рамки и размеры фигур
public/sprites/          PNG (tower_<тип>_<уровень>, enemy_*, enemy_<тип>_<уровень>, boss_1..5, binder, binder_triple, castle) и sprites.json
```

`sprites.json` для каждой фигуры хранит размер файла, `drawH` (высота на поле в px; файл втрое
крупнее), точку привязки по низу (`anchorX`, `anchorY`) и `facing` (куда смотрит на листе).
Перенарезка: `python3 scripts/slice_sprites.py` (нужны numpy и Pillow).
Лист-каталог всех персонажей с подписями — `docs/characters.png`; пересобрать: `npm run dev`, затем
`node scripts/character_sheet.mjs` (нужен Playwright, фигуры рисует сам движок). Враг рисуется спрайтом своей
фракции `enemy_<тип>_<уровень>` в его цветах, если такой есть; иначе общий `enemy_<тип>` получает оттенок
цвета фракции кодом. Анимация — только преобразования спрайта в `engine.ts`: шаг врага
(`GAIT`, от пройденного пути), парение летунов, дыхание и отдача башни после выстрела, падение
убитого врага (`corpses`, не больше 30), кольца уровня и значок специализации башни рисуются кодом. Связанная пара — два одиночных спрайта своих уровней
в полный размер, по диагонали в одной клетке (основная выше и сзади, вторая ниже и спереди), и эффект `drawBond`: бирюзовое свечение оснований и маленький пульсирующий кристалл между ними,
сила растёт с уровнями обеих частей; у Стрелка и Мага светлая обводка основания (`TOWER_RIMS`) для тёмных карт. Значок свойств под башней — двухбуквенные коды с силой
(`specBadge` в `towerStats.ts`: «Ог×2·Мр»), у пары из связки свой значок у каждой башни. Если спрайт не
загрузился, движок рисует прежние геометрические фигуры. Связка на поле — кристальный столп (`binder`), тройная — кристальная корона (`binder_triple`), замок — кольцо
с тремя опорами (`castle`, выше клетки; выбор Артура 2026-10-30); связки, башни и замок рисуются в одном порядке
по глубине. Врагов на поле рисуем крупнее файла:
`ENEMY_DRAW_SCALE` ×2,2, боссов `BOSS_DRAW_SCALE` ×3,5 (только отрисовка, радиусы и баланс не меняются).

## Игровые правила (кратко)

- 5 уровней, у каждого своя фракция с особенностью и боссом; 12 волн, в последней — босс.
- Бесконечный режим (выбор в меню, `engine.endless`, `CONFIG.endless`): 12 волн повторяются по кругу
  (`waveDefinition`), босс каждую 12-ю волну, HP растёт с номером волны без предела, каждый пройденный
  круг даёт +25 % врагов, между волнами 45 с. Победы нет, хранится рекорд волны. С 13-й волны HP растёт ещё
  на 3,5 % за волну (`endlessGrowth`), босс растёт с волной и с 24-й в 1,5 раза крепче (`bossFactor`), броня и
  сопротивление магии +4 % за круг до 60 % (`endlessArmorBonus`); числа — `CONFIG.endless` (выбор Артура «Б», 2026-10-26).
  Сила стола (`CONFIG.supply`, бесконечный режим и дуэль — у каждого игрока свой стол, в кампании цены прежние; выбор Артура 2026-10-26): вес башен Ур.1/2/3 = 1/3/9, связка 1
  (тройная 3); выше 30 каждые 20 силы цена покупки башен и связок ×1,12 (`calculateSupplyMult`, `engine.towerPrice`,
  `binderPrice`), продажа 60 % базовой цены (`engine.sellRatio`; в кампании 70 %); после 12-й волны награда за убийство ×0,985 за волну, не ниже ×0,3 (`calculateKillGold`; выбор Артура «В», 2026-10-26); вес и множитель видны в `TopBar`. Бот-проверка на тяжёлой: до этого
  доживал до волны 120+, теперь 36–48 (`node scripts/balance_sim.mjs out.json --only=endless --difficulty=hard`).
- Дуэль (выбор в меню, `engine.duelStart`, `CONFIG.duel`, выбор Артура 2026-10-25): двое игроков, у
  каждого своё поле, по сети идут только сообщения (`DuelMessage`: старт, жизни и волна раз в 2 с,
  поражение, выход). У каждой стороны случайный id (`pairedLink` в `duel.ts`): после старта сообщения идут
  только сопернику, третьему, кто войдёт по коду, хозяин отвечает `full`. Волна N выходит у обоих через N раундов по 60 с от старта, поверх недобитой;
  половина обычной волны, рост как в бесконечном режиме, скорость ×1, пауза не останавливает бой.
  Проиграл тот, чей замок пал; выход или 30 с тишины — победа соперника. Звёзд и рекордов дуэль не даёт.
  Вкладка «Армия» (`ArmyPanel`, `engine.buySend`): враги за золото уходят сопернику с началом следующей
  волны (`receiveSend` ставит их в очередь). Цена — 2 × награда за убийство × рост HP волны
  (`calculateSendPrice`), каждая посылка навсегда даёт 1/5 цены к золоту каждого следующего раунда
  (`duelIncome`), за убитого присланного врага — половина награды.
  Армия: каждый в комнате выбирает фракцию, её враги (особенность, босс, вид) идут на поле соперника —
  `engine.faction` (вне дуэли равна уровню); числа (HP, награды) — по карте `engine.level`.
  Проверка без сети: две вкладки с `?duel=local`.
  Бот (`src/duelBot.ts`, «Играть с ботом»: лёгкий, средний, сильный): соперник без поля — его защита число
  `botStrength`, против него вес волны `waveWeight` (в ценах посылок) плюс присланное вами; перегрузка
  отнимает жизни, раз в раунд он шлёт врагов на долю `sendShare` веса волны. Числа — в `BOT_LEVELS`.
- 4 башни (Стрелок, Жрец, Маг, Баллиста), по 3 специализации. Три башни одного типа и уровня
  сливаются в башню следующего уровня (макс. 3). Ур.3 хранит специализации всех трёх башен Ур.2
  (`Tower.specs`), повтор одной специализации — её сила n: прибавка ×n, недостатки как при n = 1
  (формулы в `src/game/towerStats.ts`).
- «Связка» (`CONFIG.binder`, шансы `CONFIG.shop.binderChances`, с 3-го яруса лавки) ставится на поле
  отдельной фигурой (`engine.binders`). Выбранная башня + «Связать» + касание башни другого вида; обе башни Ур.2 или Ур.3 в любом сочетании (`CONFIG.binder.minLevel`, `canBindLevels`; связка — особенность людей, выбор Артура 2026-10-30):
  вторая башня становится `Tower.second` (стреляет из той же клетки своими параметрами), связка
  тратится. Связанные башни не сливаются. Три связки сливаются в тройную (`Binder.triple`, выбор
  Артура; сливаются только с 5-го яруса лавки, `CONFIG.binder.tripleFromTier`): она поднимает любую башню или пару на уровень (каждую её часть ниже Ур.3,
  `upgradeWithBinder`); у выбранной башни, которую можно поднять, при тройной связке на поле есть кнопка «Усилить» (U, `upgradeSelectedTower`, тратит ближайшую); Ур.1 → Ур.2 просит свойство, Ур.2 → Ур.3 повторяет своё свойство трижды.
  Жрец без свойства метит цель и врагов в 1 клетке: замедление 30 % и +15 % урона от всех башен на 3 с
  (`CONFIG.priestBase`, выбор Артура 2026-10-26); башня, связанная с Жрецом, стреляет на +20 % сильнее.
  Связка заменяет третью башню при слиянии двух одинаковых: обычная — для двух башен Ур.1, тройная — для
  двух башен Ур.2 (`mergeStandIn`; на Ур.3 связка повторяет свойство выбранной башни).
- Рюкзак (`CONFIG.backpack.slots` = 6, `engine.backpack`, выбор Артура 2026-10-26): карточка лавки оплачивается сразу и падает в рюкзак (`buyToBackpack`), слот сразу берётся в руку; выбор не сбрасывается началом волны и обновлением лавки. Слот ещё раз — убрать из руки; «Продать» возвращает всё уплаченное. Башни в рюкзаке в силу стола не входят, пока не поставлены. Купить можно и при полном рюкзаке: покупка ждёт в руке, её нужно поставить на поле или тапнуть слот — тот товар продаётся за всё уплаченное, купленное занимает его место (`overflowPending`).
- Состав следующей волны (`nextWaveComposition`, пока идёт таймер; в дуэли — своя ближайшая волна) и итоги зачищенной волны (`WaveSummary`: убито, прорвалось, золото, потеряно жизней, урон каждой башни; считается в `applyDamageToEnemy` и при ожоге, проданные башни и посторонний урон — «прочее»; слитые волны дают одну сводку) показываются в `WaveInfo` над полем, во всех режимах (выбор Артура 2026-10-26, П6 и П7). В конце забега экраны победы, поражения и итога дуэли показывают `RunSummary` (`RunStats.tsx`): волны, убито, прорвалось, золото, потеряно жизней, игровое время и урон башен за весь забег; башни, которых уже нет (проданы, слиты), идут в «остальные».
- Автостарт (кнопка «Авто» рядом с волной, `engine.autoStart`, ключ `dark_frontier_autostart`): сразу после зачистки волны начинается следующая, с бонусом за ранний старт; в дуэли выключен.
- Приближение поля (`CONFIG.view.maxZoom` ×2,5, выбор Артура 2026-10-30, только отрисовка): щипок двумя пальцами,
  щипок трекпада или Ctrl + колесо у курсора; колесо, двумя пальцами по трекпаду или перетаскиванием (одним пальцем)

  `screenToField` переводит точку холста в точку поля. Касание срабатывает при отпускании, чтобы первый палец щипка ничего не ставил.

  бесплатно переставить на свободную клетку: касанием клетки или перетаскиванием.
