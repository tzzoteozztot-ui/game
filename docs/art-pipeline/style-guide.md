# Стайл-гайд графики «Тёмного рубежа» (по новому Пограничью)

Версия 1, 2026-11-01. Эталон — Пограничье из PR #74 (скриншоты `game-screens/tiles-frontier/`).
Образцы для приложения к запросам лежат рядом: `ref-tiles-frontier.jpg` (лист тайлов), `ref-decor-frontier.png` (лист декора).

## 1. Общее

- Вид поля строго сверху. Свет без направления: никаких теней в одну сторону, тайл должен поворачиваться на 90° без шва.
- Слои по яркости: поле (земля, дорога, декор) — среднее по тону и спокойное; персонажи, башни, эффекты — ярче и контрастнее поля. Поле не спорит с юнитами.
- Масштаб: клетка на телефоне ~49 px, в игре тайл запекается в 128 px. Всё мельче 1/8 клетки на телефоне не видно — рисунок крупный, без мелкой пестроты.
- Центральный объект (артефакт-кольцо) не перерисовываем. Следы чужих фракций на карте не рисуем: на каждой карте только хозяева биома.

## 2. Тайлы земли и дороги

Набор на карту — 7 тайлов 256×256: тупик, прямая, поворот 90°, Т-развилка, перекрёсток, «трава» (строительная клетка), «земля».

- Дорога по центру тайла, ширина ~104 px из 256 (≈ 40 %, полоса 78–182 px), как на прямой Пограничья. Выход дороги на стык у всех тайлов одинаковый.
- Кромка дороги — ровная полоса, мягкий переход в 6–10 px, без грязи, наползающей на соседнюю клетку.
- «Трава» — спокойная, без заметного рисунка: на ней стоят башни, повторяется ~60 раз на поле.
- Средний цвет Пограничья для сравнения: трава RGB 75/97/26, земля 138/112/85.
- Лист: сетка тайлов без подписей и рамок, однотонный тёмный фон между тайлами (как `ref-tiles-frontier.jpg`). Т-развилку, если не вышла, соберу сам из перекрёстка и прямой.

## 3. Мелкий декор (по краям свободных клеток)

- Стиль как `ref-decor-frontier.png`: рисованный, тёмный контур, приглушённые цвета.
- Размер на поле — 0,25–0,36 клетки, поэтому силуэт простой и узнаваемый.
- Фон листа — чистая маджента #FF00FF одного цвета по всему листу, без градиента и перехода (вырезаю её скриптом). Эту фразу писать в КАЖДЫЙ промт. Без теней-подложек под предметами, предметы не касаются друг друга.
- Мелкий декор не мешает строить: башня ставится поверх. Крупный декор (заборы, знамёна, большие камни) — пока не ставим, ждёт решения Артура.

## 5. Персонажи и башни

- Лист 1536×1024, фигуры в профиль, смотрят вправо, ровный светло-серый фон, без подписей, рамок и теней, не касаются друг друга.
- К запросу всегда прикладывать полосу готовых фигур фракции (`reference/faction-strips/`): «в точно таком же стиле, готовых не перерисовывать».
- Силуэт читается на 34–72 px, цвета фракции: орки оливково-бурые, нежить кость и зелёное свечение, культисты бело-голубые, демоны красно-чёрные с огненными трещинами, тёмные эльфы сине-чёрные с бирюзой, люди сталь, тёмно-синий, золото, синие кристаллы.

## 6. Приёмка картинки (проверяю я перед встраиванием)

1. Вид сверху, нет направленных теней.
2. Тайлы: ширина и положение дороги как у эталона, стык двух любых тайлов без ступеньки.
3. Фон листа однотонный (маджента для декора, серый для персонажей), подписей нет.
4. На телефоне (49 px клетка) предмет узнаётся, поле не ярче юнитов.
