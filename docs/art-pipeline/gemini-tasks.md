# Задачи для Gemini (правка готового)

Gemini получает готовую картинку и меняет в ней материал или исправляет ошибку. С нуля не рисует.
Готовое присылать в тред «Наладить конвейер графики»: нарезку и встраивание делаю я. Стиль — `style-guide.md`.

## Порядок

1. Тайлы «Болотного склепа» — ГОТОВО (PR #97, в main, 2026-11-01).
2. Тайлы «Ледяных пустошей» — ГОТОВО (PR #98, в main; снег приглушён при нарезке).
3. Тайлы «Выжженных земель» — ГОТОВО (PR #99, в main).
4. Тайлы «Цитадели сумерек» — ГОТОВО (PR #100, в main).
5. Два варианта травы Пограничья (меньше повторов на поле).
6. Починка по ходу: всё, что пришло от GPT или Gemini с ошибкой (шов, тень, лишний предмет, не тот фон).

## Общий промт перекраски тайлов (п. 1–4)

Приложить: `art-pipeline/ref-tiles-frontier.jpg`. В квадратных скобках — подставить из таблицы ниже.

```
Перерисуй этот лист тайлов под другую карту, НИЧЕГО НЕ СДВИГАЯ. Остаются точно как есть: раскладка листа, размер и положение каждого тайла, тёмный фон между тайлами, форма, ширина и положение дороги на каждом тайле, кромка дороги в местах выхода на край тайла. Вид строго сверху, свет без направления, без теней в одну сторону. Меняется только материал:
- вместо травы: [ЗЕМЛЯ];
- вместо грунтовой дороги: [ДОРОГА];
- вместо мелких цветов и кустиков на траве: [МЕЛОЧИ].
Плитка «трава» (вторая во втором ряду) — спокойная, без заметного рисунка: на ней будут стоять башни. Яркость поля средняя и приглушённая, без ярких пятен свечения. Без подписей и рамок.
```

| Карта | [ЗЕМЛЯ] | [ДОРОГА] | [МЕЛОЧИ] |
|---|---|---|---|
| 2 Болотный склеп | тёмный влажный мох и болотная трава, тёмно-зелёная с серым | топкая серо-зелёная гать: грязь с вдавленными досками, мелкие лужи с еле заметным бледно-зелёным отсветом | редкие пятна мха, мелкие косточки |
| 3 Ледяные пустоши | снег с настом, холодный бело-голубой с синими тенями, не ярко-белый | утоптанная дорога в снегу: серо-голубой лёд и колея, без луж | редкие пучки сухой травы из снега, мелкие льдинки |
| 4 Выжженные земли | серо-бурый пепел и растрескавшаяся сухая земля | тёмная выжженная дорога, по краям тонкие неяркие тлеющие трещины | угольки, мелкие обугленные стебли |
| 5 Цитадель сумерек | тёмная сине-фиолетовая трава | дорога из тёмных каменных плит сине-серого цвета, швы между плитами | мелкие тёмные цветы с бирюзовым отсветом |

Плитку «земля» (третья во втором ряду) — тем же материалом, что дорога, но без колеи.

## Варианты травы Пограничья (п. 5)

Приложить: `public/tiles/frontier/grass.png` из репозитория (или вырезать вторую плитку второго ряда из `ref-tiles-frontier.jpg`).

```
Сделай два новых варианта этой плитки травы 256×256: тот же цвет, та же зернистость и та же яркость, но другой случайный рисунок травинок и мелких растений. Края должны стыковаться с исходной плиткой и друг с другом без шва. Вид строго сверху, без теней. Три плитки рядом, на тёмном фоне, без подписей.
```

## Типовой запрос на починку (п. 6)

```
Исправь на этой картинке только [что не так: шов на правом краю / тень справа у камней / фон не однотонный / лишний предмет №…]. Всё остальное оставь точно как есть.
```
