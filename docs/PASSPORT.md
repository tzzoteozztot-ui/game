# Паспорт проекта «Тёмный рубеж»

Состояние на 2026-11-13 (последний PR на момент записи — #182). Документ для любого ИИ-помощника (Claude Code, ChatGPT Codex, Gemini CLI, Cursor), который продолжает работу. Читать вместе с `CLAUDE.md` (подробная карта кода и механик — самый полный источник) и `AGENTS.md`. Если паспорт и код расходятся, прав код; если паспорт и последнее сообщение Артура расходятся, прав Артур.

## 1. Что это

Браузерная tower defence в стиле тёмного фэнтези, альфа. React 19 + Vite 8 + TypeScript + Tailwind 4, свой движок на Canvas 2D (без игровых библиотек), звук синтезируется через Web Audio. Фигуры башен, врагов и боссов — спрайты из `public/sprites/`, остальное рисуется кодом. Выкладка: https://tzzoteozztot-ui.github.io/game/ (GitHub Pages из `main`). Репозиторий публичный.

Владелец и единственный игрок-тестер — Артур. Играет на телефоне (альбомная ориентация, касания) и на Mac (клавиатура). Общение по-русски; пишет кратко, иногда неточно. Если задачу можно понять двояко, спросить, а не угадывать.

Режимы: поход-кампания за людей (главы 1–5, глобальная карта на гексах, герой Рен Корвин, лагерь, диалоги) — основной сюжетный режим; Потасовка на 8 игроков/ботов (сеть по коду, свой лобби-канал) — основной соревновательный режим, баланс прежде всего в ней; бесконечный режим; дуэль (2 игрока или бот); свободный режим-песочница с редактором карт. Шесть играбельных рас: люди, орки, нежить, культисты, демоны, тёмные эльфы. Пять карт: Пограничье, Болотный склеп, Ледяные пустоши, Выжженные земли, Цитадель сумерек.

## 2. Как запустить

```bash
npm install
npm run dev        # http://localhost:3000, слушает 0.0.0.0 (с телефона по IP в той же сети)
npm run lint       # tsc --noEmit
npm test           # node:test через tsx, src/game/logic.test.ts
npm run build      # dist/
```

Проверка после каждой правки: `npm run lint && npm test && npm run build`. Перед запуском на Mac убедиться, что на порту 3000 нет старого сервера. Бот-баланс: `node scripts/balance_sim.mjs out.json [--runs=N] [--only=endless|campaign|mono|brawl] [--race=…]` (нужен Playwright, запущенный дев-сервер). Подробности — раздел «Команды» в `CLAUDE.md`.

## 3. Правила работы (действуют)

1. **Интерфейс только по-русски.** Все строки, видимые игроку, — по-русски. Идентификаторы и комментарии — в стиле окружающего кода.
2. **Без внешних сервисов, кроме аккаунтов.** Ни аналитики, ни CDN, ни `.env`-секретов. Единственное исключение (выбор Артура, 2026-10-24): необязательный аккаунт на Supabase (`src/cloud.ts`, вход по коду из письма, синхронизация прогресса). В коде только публичный anon-ключ, доступ ограничен RLS. Ключ `service_role` в репозиторий не класть никогда. Репозиторий публичный: в коммиты не попадают личные данные, e-mail, токены.
3. **Баланс и механика.** Числа в `src/game/config.ts` и формулы в `src/game/rules.ts` меняются только по просьбе Артура или после его выбора из вариантов. Рефакторинг без изменения поведения можно. При визуальных правках баланс не трогать.
4. **Одна правка — один коммит**, после каждой — lint, тест, сборка. Работа в отдельной ветке, PR.
5. **Вливание в `main`** (решение Артура 2026-11-12, перекрывает старую строку «без явного да»): всё, что не влияет на баланс (интерфейс, баги, сохранения, тексты, графика), вливать в `main` без его «да» и не переспрашивать, когда CI зелёный. Правка баланса или механики с числами — только после его слова. Если не уверены, влияет ли правка на баланс, — считать, что влияет, и спросить.
6. **Телефон и клавиатура.** Всё должно работать и на касаниях в альбомной ориентации, и с клавиатуры.
7. **Относительные пути.** Сборка с `base: './'`, поэтому пути к ресурсам в коде — `sprites/…`, а не `/sprites/…`.
8. **Несколько равноценных вариантов** — спросить Артура коротко: 2–3 варианта, критерий сравнения, рекомендация. Если оптимум очевиден — решать самому и сказать, что выбрано.
9. **Не дублировать работу**: перед задачей проверить открытые PR и ветки.
10. **Обновлять `CLAUDE.md`** (карту кода и механик) вместе с изменением поведения — это главная память проекта. При изменении формул или карт обновлять `logic.test.ts`.
11. Выкладка: `.github/workflows/pages.yml` на каждом PR гоняет lint, тест и сборку, при вливании в `main` выкладывает `dist/` на Pages.

## 4. Действующие решения по игре

**Поле и вид.** Гексовое поле «остриём вверх» 14×8 во всех режимах (с 2026-11-06), вид строго сверху, задники биомов, тайлы и декор у всех пяти карт. Центральный магический объект («артефакт», кольцо с кристаллом) не заменять и не перерисовывать. Артефакт имеет 200 прочности; дошедшие враги стоят у него и бьют; у артефакта есть защита, растущая с ярусом лавки.

**Башни и экономика.** Слияние трёх одинаковых башен в следующий уровень (у рас своя кратность, см. `CONFIG.races`). Связка двух башен — особенность людей, только Ур.2/Ур.3. Рюкзак на 6 слотов со стопками одинаковых башен. Лавка по ярусам; ярус и защита артефакта — одна покупка. Пять типов урона (физический, огонь, лёд, молния, яд); у фракций стойкость ×0,75 и слабость ×1,25. Подробные числа — в `config.ts` и `CLAUDE.md`.

**Потасовка** — основной режим: восемь игроков или ботов, раунд 40 с, волны в расе соперника, перестановка башни в бою за 10 золота, усиления артефакта каждые 4 волны, просмотр чужого поля вживую, лобби по коду, лог партии для разбора баланса. Рейтинг (формула и название режима) не выбраны. Ускорение каждые 6 волн отменено Артуром.

**Кампания.** Поход Рена Корвина по глобальной карте (гексы, туман, ходы в день, лагерь с пассивками, умения героя, предметы, события с выбором, бои отрядов и с армией у крепости, обучение в бою, сохранения, облачное сохранение, редактор карты, дневник задач, лог похода). Глава 1 — обучение (Пограничье), главы 2–5 — Болотный склеп, Ледяные пустоши, Выжженные земли, Цитадель сумерек (в редакции Артура от 2026-11-07). Числа глав — черновик. Старая кампания из 5 уровней со звёздами удалена. Героя в Потасовку не переносить.

**Лор (канон, 2026-10-30 … 2026-11-10).** Континент орков и эльфов в равновесии; пришлые — культисты (другой, ледяной мир; сеть древних артефактов; призвали демонов, исказили эльфов в тёмных), демоны, люди (экспедиция-экспансионисты, форпосты у магических объектов; захватчики, тексты не делают их правыми). Нежить — чума без цели; Лич Ксаар — бывший эльфийский маг, защищает склеп. Игрок защищает лагерь людей. Война всех против всех. В игре фракция зовётся «Культисты льда». Артефакты — узлы сети; у каждой расы своё слово для него, люди говорят «артефакт». Герои: Рен Корвин (сын короля, длинные тёмные волосы в хвост), Каллен (рыжий, борода), Мельхиор (молодой), Сефира (темнокожая). Без крови в главе 1. Полный лор: `docs/lore/lore-bible.md`, главы — `docs/lore/campaign-*.md`.

**Графика.** Главная проблема игры по мнению Артура. Нравится вид Пограничья (тайлы), дальше в том же духе. Стиль портретов диалогов утверждён 2026-11-13: графическая новелла, плотный чёрный контур, плоские заливки, детальные лица, тёмная состаренная бумага; образец — `docs/gemini/dialog-concepts/FINAL-style-reference.jpg`. У Рена и Каллена небольшой ромбовидный бирюзовый кристалл на предплечье. Картинки Артур делает сам в GPT (3–4 в сутки) и Gemini (хорошо правит готовое, хуже создаёт с нуля); помощник нарезает их скриптами `scripts/slice_*.py` и встраивает. Пайплайн: `docs/art-pipeline/style-guide.md`.

**Звук.** Свои записи Артура кладутся в `public/sounds/` и описываются в `sounds.json` (см. `public/sounds/README.md`); без файла играет синтез из `src/game/audio.ts`. Озвучка реплик: VoiceStudio (модель OmniVoice, лицензия некоммерческая) — в работе у Артура.

**Режим разработчика.** Заметки прямо в игре (категории, снимок состояния, выгрузка JSON); включается 7 касаниями по заголовку «Настройки» или `?dev=1`. Артур присылает файл заметок или лог партии/похода — их нужно разобрать и реализовать правки. Баланс разбирается по таким логам, оценочные «пробные» треды не запускать.

| Направление | Статус | Что осталось |

## 7. Где что лежит

- `CLAUDE.md` — подробная карта кода, механик, ключей `localStorage`, правил; обновляется с каждой правкой.
- `docs/roadmap.md` — дорожная карта и журнал идей по номерам.
- `docs/lore/` — лор, хроника, главы кампании (сценарии диалогов), таблицы башен рас, имена врагов.
- `docs/design/`, `docs/reports/`, `docs/audit/` — проекты, отчёты тестов и баланса, аудит боссов.
- `docs/art-pipeline/`, `docs/gemini/`, `docs/gpt/` — промты и правила для графических ИИ, образцы стиля.
- `docs/ASSETS.md` — что осталось вне репозитория (большие картинки и скриншоты).
- `supabase/progress.sql` — таблица прогресса и RLS.
- `scripts/` — нарезка спрайтов, тайлов, декора, бот баланса, генерация диалогов из сценариев.

## 8. Как продолжить за минуты

1. Прочитать `AGENTS.md`, этот паспорт и `CLAUDE.md`.
2. `npm install && npm run dev`, открыть http://localhost:3000, пройти меню → «Кампания».
3. `npm run lint && npm test && npm run build` — должно быть зелёным.
4. Взять задачу из раздела 5 или из просьбы Артура, работать в отдельной ветке, PR в `main`.
5. Правка не про баланс и CI зелёный — вливать без вопроса. Про баланс — спросить.
