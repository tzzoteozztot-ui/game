# Материалы вне репозитория

Репозиторий публичный и должен оставаться лёгким, поэтому крупные картинки и архивы остались в файлах проекта Claude («Хаб», папка проекта). Если нужны — скачать вручную и положить в `art/` или вне репозитория (не коммитить мегабайты без нужды).

В репозитории уже есть: `public/` (спрайты, тайлы, фоны, портреты Рена с эмоциями, звуки), `art/concepts/` (исходные листы), `docs/characters.png` (каталог персонажей), в `docs/gemini/dialog-concepts/` — образец стиля портретов и портреты-референсы.

Не перенесено (папка → что там):
- `art-pipeline/incoming`, `art-pipeline/ref-*`, `art-pipeline/ref-towers`, `art-pipeline/fix` — присланные листы дорог, образцы тайлов, декора, башен рас (7,5 МБ).
- `game-screens/` (87 МБ) — скриншоты игры по этапам (адаптивность, гексы, меню, Потасовка, карта похода, таблица урона).
- `gemini/` — `gemini-paket.zip` (7,7 МБ, пакет референсов для Gemini), `01…09_*.png` (образцы стиля, схема сетки, спрайты), `ch1/` (портреты главы 1: v1–v4, `refs-ch1.zip`, листы Рена), `dialog-concepts/` — лист GPT `STYLE-SHEET-gpt*.png` (2,6 МБ), попытки A–G, эмоции Рена `ren-emotions/` (нужные файлы уже в `public/portraits/`).
- `reference/` — справочный лист персонажей, полосы фракций, листы новых спрайтов.
- `maps-screens/`, `characters/`, `tower-sprites/` — скриншоты карт, интерактивный каталог персонажей, исходные спрайты башен.
- `lore/lore-bible.pdf`, `lore/numbers-reference.pdf` — PDF-версии (текст лора есть в `docs/lore/lore-bible.md`).
- `lore/campaign/chapters-2-5.md` — сводный файл глав 2–5 (178 КБ), дублирует `docs/lore/campaign-ch2…5`.
- `uploads/` — присланное Артуром в чатах.

Не перенесено и по другой причине: `passport.md` и `description-full.md` — рабочие инструкции управляющего проекта Claude, содержат личные сведения и другие проекты Артура; игры касается только то, что вошло в `docs/PASSPORT.md`.
