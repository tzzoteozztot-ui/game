# Свои звуки и музыка

Игра сама подхватывает записи из этой папки. Что нужно: положить файлы рядом и записать их в `sounds.json`.
Для событий без записи играет прежний синтез, поэтому добавлять можно по одному звуку. Перезапускать и пересобирать код не нужно
(только обновить страницу; на GitHub Pages — влить файлы в `main`).

Форматы: `.ogg` или `.mp3` (читаются везде), `.wav` тоже можно, но он тяжёлый. Короткие звуки — до 1–2 секунд, мало весят.

## sounds.json

```json
{
  "shot.archer": ["archer1.ogg", "archer2.ogg"],
  "hit": "hit.ogg",
  "ui.click": "click.ogg",
  "music.menu": "menu.mp3",
  "voice.start.1": "voice/start_1.ogg"
}
```

Значение — один файл или список; из списка каждый раз берётся случайный вариант. Путь — от папки `public/sounds/`.

## Ключи

| Ключ | Когда звучит |
|---|---|
| `shot.archer`, `shot.mage`, `shot.ballista`, `shot.priest` | выстрел башни (не чаще 16 раз в секунду на вид) |
| `hit` | попадание по врагу |
| `death` | гибель врага |
| `buy` | покупка, награда, постройка |
| `error` | отказ (не хватает золота, нельзя поставить) |
| `merge` | слияние башен |
| `boss` | выход босса |
| `victory`, `defeat` | победа и поражение |
| `ui.click` | нажатие любой кнопки интерфейса |
| `map.event` | открылось событие на карте похода |
| `dialog.line` | новая реплика диалога |
| `voice.<сцена>.<номер реплики>` | озвучка реплики диалога (номер с 1; сцену узнать в режиме разработчика — в заметке есть `id` сцены и номер реплики) |
| `music.menu`, `music.world`, `music.battle` | музыка меню, карты похода и боя; играет по кругу, переход плавный. Нет записи — звучит синтезированная |

Громкость музыки и эффектов — ползунки в настройках, как и раньше; голос идёт по громкости эффектов.
