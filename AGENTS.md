# Тёмный рубеж — инструкции для ИИ-помощников

Браузерная tower defence (React 19 + Vite + TypeScript + Tailwind, свой движок на Canvas 2D). Владелец — Артур, общение по-русски.

**Сначала прочитать:** `docs/PASSPORT.md` (состояние, решения, открытые вопросы, как продолжить) и `CLAUDE.md` (подробная карта кода и механик; главный источник, не противоречить ему).

## Главное

- Интерфейс игры только по-русски. Комментарии и идентификаторы — как в окружающем коде.
- Без внешних сервисов, кроме необязательного аккаунта Supabase (`src/cloud.ts`). Репозиторий публичный: никаких секретов, `.env`, `service_role`, личных данных в коммитах.
- Баланс (`src/game/config.ts`, формулы `src/game/rules.ts`) и механику с числами менять только по просьбе Артура; рефакторинг без смены поведения можно.
- Одна правка — один коммит. После каждой: `npm run lint && npm test && npm run build`.
- Работать в отдельной ветке, PR в `main`. Правки, не влияющие на баланс, при зелёном CI вливать без «да» Артура (решение 2026-11-12); правки баланса — только после его слова. Если неясно, влияет ли правка на баланс, — спросить.
- Работает и на телефоне (касания, альбомная ориентация), и с клавиатуры. Пути к ресурсам относительные (`sprites/…`).
- Если задачу можно понять двояко или равноценных вариантов несколько — спросить Артура коротко (2–3 варианта, критерий, рекомендация); иначе решать самому.
- Менять поведение — обновлять `CLAUDE.md`; менять формулы или карты — обновлять `src/game/logic.test.ts`.

## Команды

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint    # tsc --noEmit
npm test        # src/game/logic.test.ts
npm run build   # dist/
```

Лор, дорожная карта, отчёты и промты для графических ИИ — в `docs/`.
